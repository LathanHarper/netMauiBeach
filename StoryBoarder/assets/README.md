# StoryBoarder media kit

These are the public-facing StoryBoarder release images. The production marks
are deterministic renders of the canonical registration geometry; the Tow-In
window is a live Visual Studio experimental-instance capture.

| File | Use |
| --- | --- |
| `storyboarder-hero.png` | Public overview and release-story hero, 1366 x 768 |
| `storyboarder-tow-in-current.png` | Current Tow-In tool-window capture |
| `storyboarder-icon-90.png` | Visual Studio extension icon, 90 x 90 |
| `storyboarder-preview-200.png` | Visual Studio Marketplace preview, 200 x 200 |
| `storyboarder-motion-icon-128.png` | NuGet package icon, 128 x 128 with transparent corners |
| `storyboarder-mark-512.png` | General documentation mark, 512 x 512 |

All PNGs are 8-bit sRGB and carry 96-DPI resolution metadata. StoryBoarder was
conceived by CodeCrafty and developed in collaboration with BreakerBytes
(OpenAI Codex), 2026.
